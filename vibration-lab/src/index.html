使用说明

  1. 选择上方实验，再调整质量、刚度和初始条件。
  2. 点击「开始实验」，或拖动时间轴查看任意时刻。
  3. 切换时程、相图、能量、激励、幅频和相频。简谐或周期实验可选择全响应、稳态并叠加分量。
  4. 保留当前曲线，修改参数后比较同一物理量。
  5. 导出 CSV 进行计算，保存参数 JSON 可复现实验设置。

本文件无需联网。电脑双击 HTML，用浏览器打开；手机请下载后使用支持本地 HTML 的浏览器打开。

单步前进 0.02 s；修改参数自动暂停并归零。图中淡线为整个实验的预览，深色线为已播放的部分。切换页面标签或进入后台时自动暂停。

网页可用键盘操作；图表精确值见下方读数或 CSV。建议在横屏下查看更多曲线细节。
