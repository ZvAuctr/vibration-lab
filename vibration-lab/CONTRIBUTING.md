# 贡献指南

1. 修改 src/ 下的计算、界面或样式。
2. 改变物理行为时，先写清假设、坐标、单位和输入定义，再添加独立解析、数值或能量基准。
3. 运行 npm run build 和 npm test。
4. 实际检查相应实验，并至少检查一个手机宽度。
5. 更新 README、CHANGELOG 和 QA，分发同一次构建的 HTML 与源码。

不要将输入插值、傅里叶截断或绘图采样称为零误差；不要在奇点附近用一个很大的有限数伪装不存在的稳态。任意时程含事件点，积分需使用实际时间间隔。

若扩展非线性、干摩擦、碰撞、参数激励或随机统计，应建立独立模型与独立验证，明确线性叠加和当前频响公式不再适用。保持原版测试通过，保留 MIT 许可证和单文件分发方式。
