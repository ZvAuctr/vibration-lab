# 贡献指南

欢迎直接复制、修改、发布这个项目。保留 MIT 许可证，并在提交时写清楚更改的物理假设与验证方法。

## 一次修改的最小流程

1. 修改 `src/` 中对应文件。
2. 如果改变物理行为，增加独立解析、数值或能量基准；不要只断言新实现等于自身。
3. 运行 `npm run build` 和 `npm test`。
4. 用浏览器检查相应实验，并至少检查一个手机宽度。
5. 在 README 和 QA 里写清新增范围、限制及实际检查结果。
6. 分发 `dist/index.html` 和源码，保证两者来自同一次构建。

## 建议后续任务

- 旋转不平衡激励：输入偏心质量与偏心距，明确力幅随转速平方改变。
- 一般周期激励：傅里叶系数、谐波叠加及截断误差。
- 任意激励：阶跃、脉冲、分段线性输入和杜哈梅积分，给出步长收敛验证。
- 阻尼识别：从同向峰值测对数减量并与理论参数比较。
- 课程内容：由任课老师校对例题、术语和适用范围，补充课堂观察单。
- 真机兼容：由同学记录 Android/iOS 各浏览器下载后打开 HTML 的实际步骤，再写入 README。

不建议把每一次教学探索都变成登录、数据库或成绩系统。优先保留单文件分发方式。
