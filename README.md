# 振动力学 · 单自由度交互实验室

面向结构动力学课堂的离线互动实验，v1.0.0。MIT 开源，原生 HTML / CSS / JavaScript，无运行依赖。

## 给老师和同学

直接使用随包提供的 `dist/index.html`，或外层的 **振动力学实验室.html**。两者内容完全相同，文件内包含全部样式、计算程序和界面。不需要安装 Node.js，不需要启动服务器，不需要联网。

1. 电脑：下载 HTML 文件，双击并选择浏览器打开。
2. 手机：先下载文件，再用支持执行本地 HTML 的浏览器打开。微信、学习通及部分系统文件预览器可能只显示附件、禁止脚本，或没有“在浏览器打开”功能；这是容器能力差异。本项目未做原生微信小程序封装。
3. 面向全班稳定分发时，可将 HTML 作为学习通资料附件；若需要“一点链接就用”，把 `dist/index.html` 放到任意静态托管服务，再在学习通发链接。首次打开托管链接需要网络，下载单文件后可离线使用。本版没有 Service Worker 缓存机制，不会自动把在线页面安装成离线应用。
4. 这次未上传到学习通、未创建公网托管，也未检查学校的具体附件政策。建议老师先用一部实际授课手机试收附件。

选择一个实验，调参数，点击开始。可暂停、重来、0.02 s 单步、改变播放速度和拖动时间轴。淡色线给出完整响应预览，深色线表示已播放部分；各图纵轴在当前完整实验内固定，避免边播放边自动缩放造成误判。运动示意按当前实验自动放大，标注像素与物理位移换算。

“保留当前曲线作对照”保存一次完整参数与曲线快照。修改参数后，时程图与相图叠加该快照；幅频图只对比同类激励；能量图专注当前实验的三种能量，不叠加快照。改变参数会暂停并归零，避免把参数切换误当成真实外力突变。

## 坐标、公式与边界情况

所有计算使用 SI：质量 kg，刚度 N/m，阻尼 N·s/m，位移 m，速度 m/s，加速度 m/s²，力 N，能量 J，时间 s，圆频率 rad/s。

- x 是质量相对地面的绝对位移，以静平衡位置为零；重力静位移已经消去。
- ωₙ = √(k/m)，Tₙ = 2π/ωₙ，c = 2ζ√(km)，ω = rωₙ。
- 自由或力激励：mẍ + cẋ + kx = F₀ sin(ωt)，自由振动时右端为零。
- 基础运动：y = Y sin(ωt)，u = x − y，mü + cu̇ + ku = −mÿ。
- 所有初始条件输入都是绝对 x₀、v₀；基础模式内部采用 u₀ = x₀、u̇₀ = v₀ − Yω。由于选用正弦输入，y(0)=0，而 ẏ(0)=Yω。
- 基础模式能量：K = ½mẋ²，V = ½ku²，E = K + V；耗散功率为 cu̇²；支座输入功率为 −ku ẏ − cu̇ ẏ。满足 Ė = P输入 − P耗散。
- 力激励放大率：X/(F₀/k) = 1/√[(1−r²)²+(2ζr)²]。
- 基础绝对位移传递率：X/Y = √[1+(2ζr)²]/√[(1−r²)²+(2ζr)²]；相对位移幅值比 U/Y = r²/√[(1−r²)²+(2ζr)²]。X/Y 的隔振阈值为 r>√2。
- ζ>0 时自由分量衰减后趋于谐波特解；ζ=0 时非共振也可能长期保留自由分量，不能把全响应当作单一稳态正弦。
- ζ=0、r=1、非零激励时没有有界谐波特解，幅频读数为 ∞，相位无定义；时域仍完整计算共振增长，不钳制物理位移。
- 零初始条件下的无阻尼精确共振解析基准：x = F₀/(2k)[sin(ωₙt)−ωₙt cos(ωₙt)]。
- 零幅值输入不会产生共振增长；传递函数奇点仍然保留。r=0 的正弦输入恒为零，而幅频曲线在 r=0 画的是 r→0⁺ 极限，两者已在界面解释。
- ζ≥1 不存在周期振荡，不显示虚构的 ωd；非零初速度可使非振荡响应穿过零点一次。
- 幅频图横轴 r∈[0,4]，纵轴自动设置且上限不超过 30。超界峰值不绘制，奇点断开，并显示文字提醒。幅频图是幅值比；零输入幅值也可以研究传递函数本身。

## 计算方法与精度

`src/physics.js` 不依赖 DOM，可单独用于后续实验。以 [q, q̇, sin(ωt), cos(ωt)] 为扩充状态，自由/力激励时 q=x，基础激励时 q=u。用常系数矩阵指数 exp(At) 推进系统，避免精确共振或临界阻尼处的分母奇异与近似分支跳变。

矩阵指数采用无穷范数缩放至 ≤0.5、收敛 Taylor 级数及反复平方；级数项最大绝对值小于 2×10⁻¹⁷ 时停止，最多 40 项。这里的计算仍是双精度浮点数计算，不宣称数学意义上的零误差。实时读数直接计算指定时刻，与动画帧率、播放倍速、绘图采样步长无关。

图表/CSV 采用均匀采样网格，目标每个最高振动周期约 100 点，至少 1800、最多 24000 个区间。每 200 步从直接矩阵指数重新锚定，限制累积舍入误差。最高频、最长时长组合时会受到采样上限与屏幕像素的限制，应缩短观察时长研究局部波形；采样数据不代表连续函数的所有极值。频响按解析公式绘制，1001 个频率点。

当前允许范围写在 `Vibration.LIMITS`：m∈[0.1,20]，k∈[1,1000]，ζ∈[0,3]，x₀∈[−0.3,0.3]，v₀∈[−3,3]，F₀∈[0,30]，Y∈[0,0.1]，r∈[0,4]，时长∈[2,60]。HTML 控件和计算内核同时验证。

## 导出与复现

CSV 为 UTF-8 BOM 编码，第一行是 `#` 开头的实验参数说明，第二行才是字段标题；用电子表格软件打开时将第一行视作说明，或用数据导入功能跳过第一行。列有 t、绝对 x/v/a、相对 u/u̇/ü、y/ẏ、质量上的外力、K/V/E、阻尼耗散功率和输入功率。基础模式的 `external_force_N` 为 0，因为它不包含等效惯性力；基础通过移动支座做功。

参数 JSON 格式：`{ "version": 1, "parameters": { ... } }`，通过界面“保存参数”和“载入参数”交换。它保存实验参数，不保存播放进度、图表选择或对照快照。载入只解析 JSON，不执行代码，限制文件体积并校验全部已知字段。

可在 Excel 中计算周期、阻尼比或验证能量；CSV 中 `input_power_W - damping_power_W` 的时间积分应与机械能变化一致。

## 维护源码

```text
vibration-lab/
  src/
    index.html           语义化界面模板
    style.css            桌面/手机响应式样式
    physics.js           独立计算内核（浏览器与 Node 共用）
    app.js               参数、动画、Canvas 图表和导出
  scripts/build.cjs      零依赖单文件构建
  tests/physics.test.cjs 独立数值验证
  dist/index.html        可直接分发的单文件
  VERIFICATION.json      最近一次实际测试结果
  QA.md                  浏览器实际检查与限制
  LICENSE                MIT 许可证
```

维护时安装 Node.js 18 或以上即可，无需 `npm install`：

```sh
npm run build
npm test
```

或直接运行 `node scripts/build.cjs` 和 `node tests/physics.test.cjs`。先修改 `src/`，再构建；不要只改生成后的 HTML。构建脚本同时更新 `dist/index.html` 和上级目录的中文单文件。测试在通过全部断言后写出 `VERIFICATION.json`。

验证包括：四种模式的初始条件、全阻尼区间解析基准、近临界参数、无阻尼周期/能量、精确和近共振、独立绝对坐标 RK4 交叉计算、RK4 步长减半收敛、有限差分运动学、运动方程残差、采样推进与直接计算一致性、能量收支、频响幅相一致性、隔振阈值、零激励、极端参数、输入验证、单文件外部依赖检查。具体阈值和参考实现见测试文件，不以程序自己的同一公式充当唯一基准。

扩展新模块时，先在计算层新增激励或模型与对应独立基准，再接入 UI 和课堂观察任务；新增周期/任意激励时应明确输入函数、时间离散策略、收敛标准与能量收支。多自由度模型建议新建计算模块，而非在当前四维状态里不断增加条件分支。欢迎下一届同学在保留许可证和验证的基础上改进。
