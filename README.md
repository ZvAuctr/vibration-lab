# 振动力学 · 单自由度交互实验室 1.0.1

可离线使用的中文单自由度振动教学平台。MIT 开源，原生 HTML/CSS/JavaScript；无需登录、数据库、服务器或安装运行依赖。

## 使用

直接用浏览器打开 dist/index.html，或 outputs/振动力学-1.0.1.html。两者内容相同，全部程序、图表与样式都在一个文件内。电脑可双击打开；手机需要能执行本地 HTML 的浏览器。某些文件预览器会禁止脚本，具体设备兼容性见 QA.md。

选择实验后调参数、播放、暂停或拖动时间轴。单步为 0.02 s，修改参数会暂停并归零。淡线预览整个实验，深线表示已播放部分。运动示意自动缩放，物理计算不钳制位移；精确值见读数与导出的 CSV。

## 1.0.1 实验范围

| 实验 | 内容 |
| --- | --- |
| 无阻尼自由振动 | 任意初位移/初速度、固有周期、相图、能量守恒 |
| 有阻尼自由振动 | 欠阻尼、临界、过阻尼；阻尼系数、对数减量与峰值识别工具 |
| 简谐力激励 | 初相位、全响应、稳态、瞬态分量、拍振、精确共振 |
| 旋转不平衡 | 偏心质量比、偏心距、转速平方相关激励、全响应与稳态、转子示意 |
| 基础运动 | 指定位移或指定加速度，绝对/相对坐标，全响应、稳态和隔振 |
| 周期激励 | 方波、三角波、锯齿波、三频叠加；最高阶数 1–21，傅里叶叠加 |
| 任意激励 | 阶跃、有限上升斜坡、矩形/三角/半正弦脉冲、理想冲量、线性扫频、自定义 CSV |

所有实验可查看时程、相图、能量与激励。谐波及周期实验还可查看幅频/相频、力或基础运动传递率。时程可选绝对位移、速度、加速度、相对位移和传递力。全响应模式可叠加位移/速度/加速度的稳态与瞬态分量。保留一次参数曲线后，可改变参数对照。

本版完整实现的是上述线性、时不变、黏性阻尼模型的确定性教学范围。单自由度这个概念还包括非线性刚度、干摩擦、碰撞、参数激励、随机振动等独立专题，本版没有实现这些模型，不将它们混入线性公式。

## 坐标与公式

统一 SI 单位：m 为 kg，k 为 N/m，c 为 N·s/m，位移 m，速度 m/s，加速度 m/s²，力 N，冲量 N·s，能量 J，时间 s，圆频率 rad/s。相位输入为度。

- ωₙ=√(k/m)，c=2ζ√(km)，Tₙ=2π/ωₙ，r=ω/ωₙ。
- x 是质量相对地面的绝对位移；y 为基础位移；u=x−y。所有输入的 x₀、v₀ 都是 t=0 的绝对初始条件。静重力平衡位移已消去。
- 固定支座：mẍ+cẋ+kx=F(t)。基础运动：mü+cu̇+ku=−mÿ，等价于 mẍ+c(ẋ−ẏ)+k(x−y)=0。
- 基础位移输入 y=Y sin(ωt+θ)，自动按实际 y(0)、ẏ(0) 转换初始条件。基础加速度输入 ÿ=Aᵍ sin(ωt+θ)，积分常数令 y(0)=ẏ(0)=0；积分后可能有绝对位移漂移，不能将其误当作数值发散。
- 基础加速度模式的“稳态”指相对响应 u 的谐波特解。绝对 x 还含积分所得的基础运动。该模式的位移频响为 U/(Aᵍ/ωₙ²)，相位相对等效惯性力 −mÿ；传递率则是绝对加速度/基础加速度，相位相对 ÿ。
- 简谐力幅频：D=√[(1−r²)²+(2ζr)²]，X=(F₀/k)/D，φ=atan2(2ζr,1−r²)，xₛ=X sin(ωt+θ−φ)。
- 旋转不平衡：总支承质量 m 包含不平衡质量 mₑ，μ=mₑ/m，F₀=mₑeω²，X/(μe)=r²/D；转速匀定，不模拟电机启停动力学。
- 力传递率 |Fₜ|/F₀=√[1+(2ζr)²]/D，Fₜ=ku+cu̇；基础位移传递率 X/Y 为同一表达式，隔振阈值 r>√2。
- 初始条件作用与稳态作用通过线性叠加分离。稳态模式忽略给定 x₀、v₀；全响应仍严格满足它们。ζ=0 时自由分量一般不会衰减。
- 任一非零谐波 nω=ωₙ 且 ζ=0 时无有界稳态。该选项禁用并说明原因，完整时域仍计算增长。零激励不会凭空共振。r=0 的输入由初相位决定，可能为零或常值；频响端点是低频极限。

## 周期波形的定义

相位 θ 以基频计，第 n 阶相位为 nθ。默认零均值，无直流分量；需要直流叠加时可用任意时程。

- 方波：仅奇数阶 bₙ=4F/(πn)。
- 三角波：仅奇数阶 bₙ=8F(−1)^((n−1)/2)/(π²n²)。
- 锯齿波：bₙ=2F(−1)^(n+1)/(πn)。
- 三频叠加：b₁=F，b₂=0.35F，b₃=0.2F；最高阶数低于 3 时相应截断。

实际施加的力和计算响应都使用最高阶数 N 的同一截断级数，不拿理想方波与截断响应混配。方波/锯齿波跳跃附近有 Gibbs 现象；本版不把 N=21 当作无限级数。周期实验的幅频/相频图显示单个单位谐波的系统频响，不把多谐波响应标成一个唯一振幅。

## 任意时程与冲量

典型荷载的开始时间 t₀、力幅 F、持续/上升时间 τ 可以调整。斜坡在 τ 内升到 F 后保持；矩形、三角和半正弦脉冲在 τ 后归零。线性扫频从 t₀ 起，瞬时圆频率由 ω 线性变为观察结束时的 2ω。

“理想瞬时冲量”在 t₀ 使 v(t₀⁺)=v(t₀⁻)+J/m，x 连续。x₀、v₀ 是冲量前的初始条件；若 t₀=0，零时刻读数为冲量后的右极限。力在该时刻含 Dirac 分布，不能用一个有限力峰值表示；激励图单独标出冲量 J。速度和机械能的跳变被保留，能量增量为 Jv(t₀⁻)+J²/(2m)，不计入普通连续功率列的积分。

自定义 CSV/文本：两列时间(s)、力(N)，可有英文标题行，逗号、分号或空白分隔。时间从 0 开始，严格递增，2–2000 行，0–60 s，|F|≤100000 N。相邻点线性连接，最后一个点之后保持末值；需撤去荷载时让末值为 0。不会执行任何用户输入代码。可下载界面中的示例，或使用 examples/load-example.csv。

## 计算与采样

原计算内核 src/physics.js 保留原版 API 和回归测试；src/sdof.js 实现扩展加载、谐波分解、初相位、传递率及识别。

自由/简谐/旋转/基础响应采用常系数状态空间矩阵指数。周期响应按谐波分别精确推进后叠加，避免时域积分对高阶谐波不稳定。共振时也不使用含 1/(1−r²) 的相消公式。

任意分段线性荷载采用扩充状态 [x,v,F,Ḟ] 的矩阵指数，每段精确推进，并在分段边界连续传递状态。它与 Duhamel 卷积等价。半正弦在 600 个区间内线性近似；扫频目标采样间隔约 1/(400ω)，最少 1000、最多 120000 段，观察结束后保持最后荷载值。高频长时扫描受上限影响，不能宣称输入插值无误差。

矩阵指数采用范数缩放、收敛 Taylor 级数和反复平方，双精度浮点计算。实时读数直接求指定时刻，独立于播放倍速和帧率。均匀图表采样以最快谐波为依据，至少 1800、最多 16000 个区间；额外保留 CSV 转折点、脉冲关键时刻和冲量左右极限，保证短脉冲不会因不落在均匀网格上而完全漏画。有限采样不代表连续曲线的全部极值。

幅频/相频横轴 r∈[0,4]，幅频纵轴上限不超过 30，超界峰值不画，奇点断开并提示；精确数值仍显示。动画位移自动缩放；波形很密时缩短观察时长。

## 能量与导出

K=½mẋ²，V=½ku²，E=K+V。耗散功率 cu̇²；力激励输入功率 Fẋ；移动支座输入功率 −kuẏ−cu̇ẏ。连续荷载下 Ė=P输入−P耗散，冲量需要另加前述能量跳变。

CSV 为 UTF-8 BOM，第一行是 # 开头的参数说明，第二行是列名。电子表格/脚本导入时跳过第一行。包含 x/v/a、u/u̇/ü、y/ẏ/ÿ、外力、方程右端等效力、传递力、K/V/E、功率、稳态与瞬态的 x/v/a。无有界稳态或非谐波实验时，相关分量留空。基础位移模式的等效力是 ky+cẏ；基础加速度模式是 −mÿ。它们不能当作直接作用于质量的外力。

任意荷载导出含额外事件点，时间间隔可能不均匀；积分时务必使用相邻时间差，而非假定固定步长。

参数 JSON 仍采用 version=1 格式，兼容原版核心字段，并为新增字段补默认值。保存参数不保存播放进度、对照快照或图表选择。examples/ 内配置可直接通过“载入参数”复现。
